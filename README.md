# TrovaCor 
A digital corpus of troubadour lyrical poetry

## Overview
TrovaCor is a digital corpus dedicated to the lyrical poetry of the troubadours. It aims to provide structured, machine-readable data to support research in medieval literature, philology, and computational text analysis.
This repository currently includes sample data for illustration purposes. The full dataset will be released here upon publication of the accompanying research paper.
## Data Description
Each poem in the corpus is represented in JSON format and includes the following fields:
authors – The poet(s) attributed to the text.
fine_grained_label – A detailed classification of the poem’s type or theme.
coarse_grained_label – A broader categorical label for genre or form.
text_full – The complete text of the poem.
stanzas – The poem segmented by stanza.
references – Mentions or allusions to other authors within the text.
